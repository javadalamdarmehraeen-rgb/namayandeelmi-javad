روش درست نصب هر نسخه جدید
--------------------------
1) zip را در یک فولدر موقت باز کن.
2) فایل CLEAN_EXTRA_FILES.bat را در فولدر برنامه خودت
   (مثلاً E:\porozheha\list prozheha\namayandeelmi-javad) کپی کن
   به‌همراه پوشه scripts و فایل OFFICIAL_FILELIST.txt
   یا کل محتویات zip را روی همان فولدر کپی کن.
3) CLEAN_EXTRA_FILES.bat را اجرا کن و Y بزن.
4) اگر آن فولدر به گیت وصل است، PUSH_GITHUB_CLEAN.bat را اجرا کن
   و در پایان Y بزن تا به GitHub پوش شود.
   یا دستی:
      git add -A
      git commit -m "chore: remove leftover extra files not in current version"
      git push origin main

روش جایگزین بدون اسکریپت (کل فولدر را عوض کن)
---------------------------------------------
1) از فولدر فعلی فقط این‌ها را نگه دار:
     .git
     .env
     .env.ndcohub
     node_modules   (اگر ساختی)
2) بقیه را پاک کن.
3) محتویات zip تمیز را جای آن بگذار.
