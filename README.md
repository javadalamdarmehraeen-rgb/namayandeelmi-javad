# ثبت اطلاعات کل

سامانه ثبت اطلاعات داروخانه، پزشک، سفارشات و رصد تردد نمایندگان علمی.
Next.js 16 (App Router) + PostgreSQL (Drizzle ORM) + PWA (قابل نصب روی ویندوز، اندروید و iOS).

## دسترسی پیش‌فرض

| نقش | نام کاربری | رمز عبور | شماره همراه ورود |
| --- | --- | --- | --- |
| مدیر | `admin` | `admin1234` | `09120000000` |
| نماینده نمونه | `rep1` | `rep1234` | `09121111111` |

> با متغیرهای محیطی `ADMIN_PASSWORD` و `ADMIN_PHONE` می‌توانید مقدار اولیه مدیر را تغییر دهید
> (فقط در اولین اجرای دیتابیس خالی اعمال می‌شود). بعد از ورود، از مسیر «نمایندگان و دسترسی» رمز را عوض کنید.

## اجرای محلی (VS Code)

```bash
npm install
# فایل .env
# DATABASE_URL=postgresql://user:pass@host/db?sslmode=require
npm run dev
```

جدول‌ها در اولین اجرا **به صورت خودکار** ساخته می‌شوند (نیازی به اجرای migration نیست).

## استقرار روی Render + Neon

1. در Neon یک دیتابیس بسازید و Connection String آن را کپی کنید (حتماً با `?sslmode=require`).
2. در Render سرویس Web Service بسازید و **حتماً** این مقادیر را تنظیم کنید:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm run start`
   - **Health Check Path:** `/api/health`
   - **Environment Variables:**
     - `DATABASE_URL` = رشته اتصال Neon
     - `APP_SECRET` = یک رشته تصادفی طولانی
     - `NODE_VERSION` = `20.18.0`
3. خطای `Could not find a production build in the '.next' directory` دقیقاً یعنی Build Command تنظیم نشده است؛
   با مرحله ۲ برطرف می‌شود. فایل `render.yaml` موجود در ریشه پروژه همین تنظیمات را به صورت Blueprint دارد.

## امکانات

- ورود با نام کاربری/رمز + بررسی شماره همراه فعال روی همان گوشی و هشدار در صورت مغایرت یا آفلاین بودن سیم‌کارت.
- ورود جداگانه مدیر و داشبورد کامل مدیریتی.
- سه کلید اصلی نماینده: ثبت اطلاعات داروخانه، ثبت اطلاعات پزشک، ثبت سفارشات داروخانه.
- تاریخ شمسی خودکار + تقویم انتخابی + ماسک تایپی (`۱۴۰۵/۰۱/۰۱`).
- ثبت لوکیشن نقطه‌ای روی نقشه به نام همان داروخانه/پزشک و نمایش آن با کلیک روی نام.
- لیست‌های کشویی قابل جستجو و تایپ (تخصص، پخش، ویزیتور) که مدیر به صورت لحظه‌ای اضافه/حذف می‌کند.
- صفحات نمایش با ستون «ردیف» و «نام نماینده» و کلید «ارسال اطلاعات» برای مدیر.
- ثبت تردد روی نقشه به صورت آنلاین و آفلاین (صف محلی + همگام‌سازی خودکار)، ساعت شروع، ثبت وقفه و پایان سفر.
- ارسال خودکار سفارش به بله، ایتا و واتساپ (شماره یا گروه، با امکان فعال/غیرفعال‌سازی).
- خروجی اکسل (CSV با انکودینگ UTF-8 مخصوص Excel) از همه بخش‌ها.
- مدیریت کاربران، رمز عبور، شماره همراه ورود و سطح دسترسی.
- رصد فعالیت لحظه‌ای نمایندگان.
